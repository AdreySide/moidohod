💰 Мой доход — калькулятор зарплаты и премий

Android-приложение для расчёта заработной платы, учёта рабочих смен и отслеживания премий. Поддерживает различные графики работы, позволяет планировать доходы и вести историю выплат.

✨ Возможности
📅 Календарь смен
Учёт рабочих дней, выходных, больничных и отпусков.
Поддержка графиков 5/2 и 2/2.
Удобное отображение рабочего графика в календаре.
💵 Расчёт заработной платы
Автоматический расчёт оклада с учётом отработанных часов и годовой нормы.
Поддержка графика 5/2 с 8-часовым рабочим днём.
Поддержка графика 2/2 с 11-часовыми сменами.
Учёт налоговой ставки.
Отображение ожидаемых выплат на главном экране.
🏆 Система премирования
Расчёт премии на основе накопленных баллов и установленного плана.
Начисление премии при выполнении плана не менее чем на 60%.
Поддержка максимального выполнения плана до 150%.
Подробная информация о прогрессе выполнения плана.
Расчёт необходимого количества баллов для достижения целей.
Определение среднего количества баллов, необходимого для выполнения плана за оставшиеся рабочие дни.
📊 История выплат
Учёт авансов, зарплат и дополнительных выплат.
Группировка выплат по месяцам.
Возможность добавлять выплаты вручную.
Учёт отпускных, больничных и других поступлений.
⚙️ Настройки
Настройка оклада и годовой нормы рабочего времени.
Выбор графика работы.
Настройка налоговой ставки.
Загрузка годовой нормы из встроенного справочника.
🛠️ Технологический стек

Приложение разработано с использованием современных инструментов Android-разработки.

Технология	Назначение
Kotlin	Основной язык программирования
Jetpack Compose	Создание пользовательского интерфейса
Material 3	Дизайн интерфейса
Room	Локальное хранение данных
Navigation Compose	Навигация между экранами
Kotlin Coroutines	Асинхронные операции
Kotlin Flow	Реактивная работа с данными
Gradle Kotlin DSL	Сборка проекта

Архитектура: MVVM.
