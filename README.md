# Мой доход — приложение для расчёта зарплаты и премий старших инженеров в пао Вымпелком


Основные возможности

- **Календарь смен:** отмечай рабочие дни, выходные, больничные и отпуск.
- **Гибкий график:** поддержка графиков 5/2 (8-часовые смены) и 2/2 (11 часов для оклада + премия).
- **Автоматический расчёт оклада:** учитывается количество отработанных часов и годовая норма.
- **Премиальная система:**
  - Реализован план баллов на основе формы рабочего графика
  - Премия начисляется только при выполнении плана ≥60% (лимит 150%).
 - Информация об ожидаемых выплатах на главной
- **История выплат:** все фактические выплаты (аванс, зарплата, ручные) группируются по месяцам.
- **Детали премии:** клик по карточке баллов открывает подробный расчёт:
  - сколько баллов нужно до 60%, 100%, 150%;
  - сколько баллов в день требуется набирать на оставшихся рабочих днях.
- **Настройки:** оклад, годовая норма, ставка налога, выбор графика, подгрузка нормы из справочника.
- **Ручные выплаты:** можно добавить отпускные, больничные и т.п.


###  Стек технологий

- **Язык:** Kotlin
- **UI:** Jetpack Compose
- **База данных:** Room
- **Навигация:** Jetpack Navigation Compose
- **Асинхронность:** Kotlin Coroutines + Flow
- **Сборка:** Gradle (Kotlin DSL)
